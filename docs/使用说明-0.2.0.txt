PPGoose 0.2.0 使用说明
2026-10-13

一、开始压缩
把 PNG、JPG/JPEG、GIF、WebP 拖入窗口，或点击“选择文件/选择文件夹”。点击“开始压缩”。报错的文件可调整设置后再次压缩。
PNG 默认细节优先；文字截图可选像素无损。GIF 保留动画；动画 WebP 暂时跳过。

二、文件写入和转换
“覆盖原文件”：同格式且未加后缀时才覆盖来源。覆盖前自动备份；结果无收益时保持原文件不变。
“compressed/ 子文件夹”或“自定义目录”：另存输出，同名自动加 (1)、(2)…，不会覆盖已有文件。
WebP 转换改变格式时始终另存，来源 WebP 保留。PNG 输出是真实 PNG 字节，不是只改扩展名；不缩小时保留解码像素。JPEG 不支持透明，透明区域合成白底。AVIF 仅作为输出。
所有结果在写入前检查实际格式。先写临时文件并同步，再原子提交；失败清理本次临时文件。

三、备份与恢复
覆盖成功后，文件行出现“恢复”。也可以从顶部“备份与恢复”找到历史记录，重启后仍可恢复。
多次覆盖同一个文件，从最新记录开始逐次恢复。恢复会校验备份与当前文件；文件已有其他改动或备份损坏时，停止恢复并显示原因。原路径的文件已丢失时，可从备份重建。
恢复后仍保留备份和记录。备份可能占用较多磁盘空间，当前没有自动清理功能。
旧版已覆盖的图片、另存文件、结果与原字节相同的文件不产生覆盖备份。

Windows 数据目录通常为：%APPDATA%\com.ppgoose.app
以“备份与恢复”中显示的路径为准。
  history.json：历史记录、文件路径与 SHA-256 校验值。
  backups/：覆盖前原图。
  previews/：对比缓存，可在关闭软件后删除，之后会重新生成。
  history.lock：跨实例操作锁。
请整体保留 history.json 和 backups/，不要只移动其中一个。
设置和当前队列只保存在本次会话，重启后恢复默认设置；历史备份持久保存。

四、图片对比
完成后点击文件行“对比”。拖动“对比位置”，左侧为原图，右侧为压缩后。
“适应窗口”用于整体查看；“原图 100%”按原图像素显示，可滚动查看细节。
尺寸不同时按原图比例对齐，窗口同时显示两侧真实尺寸。透明区域有棋盘背景。
GIF/APNG 只比较首帧，输出文件仍保留动画。文件或备份已被更改时，拒绝显示旧记录的对比。

五、目标大小控制
设置“目标大小（KB）”，例如 200 表示输出不超过 204800 B。留空关闭限制。
软件先尝试当前编码设置，再搜索质量档位。最低编码质量默认 40，手动质量作为搜索上限；这些数字不是视觉质量或 DSSIM 保证。
默认保留原尺寸。勾选“必要时允许等比例缩小尺寸”，才会自动进一步缩小以尝试满足目标。也可以直接填写“最长边（像素）”，如 1920。
尺寸缩小会在文件行显示实际尺寸。成功结果显示“已达目标”；达不到目标会报错，不写输出、不覆盖原文件。
像素无损 PNG、APNG 保持原尺寸。WebP 转 PNG 不通过有损量化凑大小；无损 WebP 保持无损编码。必要时可调整目标，或选择适用的尺寸策略。
目标大小模式与极致模式互斥。目标搜索最多尝试五组尺寸，因此非常小的目标可能仍无法满足。

六、验证范围
已验证 Windows 本机的编译、编码与文件回归；界面交互另做浏览器检查。跨平台设计保持，但此次没有在 macOS/Linux 真机验收。


2026-10-14 独立核心更新补充
设置新增 JPEG 策略：均衡保持原默认；细节优先保留更多色彩边缘；紧凑压缩自动质量 67。
细节和紧凑压缩均为有损压缩，可能比均衡更大；手动质量、极致模式或目标大小会调整质量。
静态 WebP 现在保留 ICC，无损重编码保留全透明区域 RGB。携带 ICC 的图片暂拒绝转 AVIF，
可改用 PNG/JPEG 或先进行明确色彩转换。桌面与 CMS 共用 crates/ppgoose-core。
CMS JSON 子进程默认另存，桌面输出默认仍覆盖并备份。详细接入见 CMS-独立压缩核心.txt。


CSV 报告
队列栏“导出 CSV”保存当前队列（完成、失败和待处理行）。压缩/恢复中暂不可导出。
使用原生保存窗口选择位置，取消不写文件；导出失败会在底部显示错误。
报告包含路径、前后字节、节省比例、尺寸、耗时、当次实际压缩配置、记录 ID、错误和提示。
耗时统计每个文件的后台压缩与写入时间，不包含排队和保存报告的时间。
报告采用带 BOM 的 UTF-8、逗号分隔和 CRLF，方便 Windows Excel 读取中文。
以公式符号开头的文本会加单引号，避免打开报告时执行文件名或错误中的公式。

Windows 右键入口
在设置中勾选“Windows 右键入口”；仅注册当前用户，无需管理员权限。
支持 PNG/JPG/JPEG/GIF/WebP 图片和文件夹。右键选择“添加到 PPGoose”。
Windows 11 的传统菜单入口可能在“显示更多选项”下。
入口只添加队列，不自动压缩或覆盖；在应用中检查选项，再点击“开始压缩”。
重复启动会把路径交给已打开的单实例窗口；冷启动也保留待添加路径，直到前端就绪。
文件夹会递归扫描。多个图片由 Explorer 的传统 Document 选择模型逐个转交。
移动 exe 后重新开启入口；删除便携版前先取消勾选。取消勾选只移除本应用的菜单项。
macOS/Linux 暂不提供这个 Windows 注册表开关。
