PPGoose 0.2.0 更新记录
日期：2026-10-14

桌面压缩
- PNG 新增细节优先、均衡、像素无损策略；默认细节优先。保护 APNG 与 16-bit PNG。
- JPEG 新增均衡、细节优先、紧凑压缩；默认保持均衡。细节/研究使用 4:4:4 与上游表 3。
- GIF 使用独立差帧无损候选与 gifski 择优，校验帧数、逐帧延迟与循环设置。
- 无损 WebP 保留透明区 RGB；静态 WebP 保留 ICC；编码失败返回错误。
- 目标大小使用 KB×1024 硬上限，可设最低质量、最长边和是否允许自动缩小。
- PNG 缩放保留色彩标签与 16 位精度；每次搜索从原始像素编码。
- 同格式未缩小时避免增大；转换扩展名核对实际编码格式。

文件与界面
- 覆盖前保存持久原图备份和 SHA-256 记录，支持重启后恢复。
- 同目录临时文件同步后原子提交；另存同名文件自动编号。
- 支持压缩前后对比、透明棋盘格、原图 100% 和动图首帧预览。
- 仅允许访问已登记并校验的预览缓存；恢复与压缩避免重叠。
- 批量任务在阻塞线程运行，事件与最终返回结果共同核对，错误行可以重试。

独立核心
- crates/ppgoose-core 无 Tauri/前端依赖；桌面与 CMS 共用同一实现。
- 内存接口 compress_bytes 提供真实输出格式与元信息，不写磁盘。
- ppgoose-cli 的版本化 JSON 协议支持压缩、历史查询和恢复；部分配置默认另存。
- 提供 Python 子进程调用、回归脚本、接入说明和跨平台 CI。
- 核心 CI 自动保存各平台 CLI 可执行文件，Windows 同时检查前端和桌面 Rust 编译。

验证
- 56 项核心、字节接口、色彩与跨进程测试通过；8 图/12 次本机 CLI 策略回归已记录。
- TypeScript + Vite 构建、桌面 Rust 检查通过。
- npm run tauri build -- --no-bundle：Windows release 桌面可执行文件构建通过。

范围
紧凑压缩不保证同等画质胜负；颜色样例通过不等于所有广色域显示已验收。
AVIF 仍仅作为输出，携带 ICC 的源暂拒绝转 AVIF，避免静默丢失 profile。
本次提交推送源码及 CI 配置；真实桌面交互、安装器和 CMS 生产环境仍需各自验收。
